# kumamoto-douro-ci

2026年7月28日に発生した熊本地震の被災地域向けに、熊本県内の市町村公式サイトが発表する
道路の通行規制・復旧情報を定時収集し、`municipal.json` として公開するリポジトリです。
収集結果は被災者向けの道路情報ページ（市町村発表セクション）から参照されます。

## 仕組み

- GitHub Actions（`.github/workflows/crawl.yml`）が30分ごとに `crawl_ci.py` を実行
- `sources.json` に登録された市町村公式ページ（全URL実アクセスで存在確認済み）を巡回
- 本文のハッシュが前回と変化したページのみ、Claude CLI（`claude -p`）で規制情報を抽出
- 変化があったときだけ `municipal.json` をコミット（このリポジトリはデータの置き場で、サイトのデプロイは行わない）

## 安全設計（誤情報防止の3フィルタ）

命に関わる情報のため、抽出結果は以下をすべて満たす項目だけを採用します。

1. **発生日フィルタ**: 記事の発表日・更新日が地震発生日（2026-07-28）より前、または日付を特定
   できないものは破棄（過去の豪雨災害等の古い規制・解除情報の混入防止）
2. **原文照合**: 抽出された路線名・引用文が取得ページの原文に実在しない項目は破棄
   （AIの転記ミス・創作の防止。照合不一致があったページは次回巡回で再抽出）
3. **巡回対象外の掃除**: `sources.json` から外れた市町村の過去データは自動削除

各項目には出典URL・原文の引用・取得時刻（JST）を必ず付けています。

## 注意

- 本データは各市町村の公開情報を機械的に集約したものです。**現地の状況が最新です。**
  通行の判断は現地の規制・誘導に従ってください。必ず出典（各市町村公式サイト）を確認してください。
- 巡回は1サイト1リクエスト・タイムアウト15秒・サイト間1秒待機で、対象サイトへの負荷を最小化しています。
- 収集対象は公的機関が公開している行政情報のみで、個人情報は含みません。

## 必要なSecrets

- `CLAUDE_CODE_OAUTH_TOKEN` — Claude CLIの認証トークン（`claude setup-token` で発行）
